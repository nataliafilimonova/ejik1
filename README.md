4.Вычисление num2: Блок вычисления числителя второго терма.
Вычисляется x + y / (x * x + 4.0)
5.Вычисление den2: Блок вычисления знаменателя второго терма.
Вычисляется exp(-x - 2) + 1.0 / (x * x + 4.0)
6.Вычисление term2: Блок вычисления второго терма.
Деление num2 на den2 и умножение на (1.0 + y)
7.Вычисление F: Блок суммирования term1 и term2 для получения результата F.
8.Вывод результата: Блок вывода значения F с использованием printf.

#include <stdio.h>
#include <math.h>

int main() {
    double x = 0.5;
    double y = 2e-5;
    double term1 = (-cos(y - 2) - 1) / (x * x / 2.0 + pow(sin(x / y), 2));
    double num2 = x + y / (x * x + 4.0);
    double den2 = exp(-x - 2) + 1.0 / (x * x + 4.0);
    double term2 = (1.0 + y) * (num2 / den2);
    double F = term1 + term2;
    printf("F(%.1f, %.2e) = %.4f\n", x, y, F);
    return 0;
}
